이번 주 RAG 연구는 **도메인 특화·멀티모달·시간 인식**으로의 확장이 뚜렷했습니다. 법령(FiscalQA Pro), 항공 정비(Cessna 172 MM), 금융 정산(FinRCA-Bench), 의료(HealMed) 등 고위험·전문 도메인에서 정적 코퍼스 가정을 깨는 벤치마크와 시스템이 다수 등장했습니다. 특히 Temporal Misgrounding(2608.09393)과 FinRCA-Bench(2608.18534)는 검색 대상이 '버전'과 '거래 관계'로 구조화돼야 함을 실증했고, 멀티모달 RAG(2608.18465)는 텍스트·이미지·다이어그램 통합 검색의 실운영 지표(리콜, 지연, 비용)를 제시했습니다. 이는 RAG가 단순 벡터 검색을 넘어 도메인 지식 그래프·시간 인덱스·멀티모달 인덱스와의 네이티브 통합(AkasicDB, 2608.09214)으로 진화 중임을 시사합니다.

**그래프 기반 RAG 지속 강세, 에이전틱 패턴과 결합 가속**이 두 번째 흐름입니다. rEDMRec(2608.18952)는 LLM 추론을 편집 가능 경험 메모리(장/단기 선호, 아이템 인지, 반사실)로 증류해 경량 학생 모델이 추론 없이 검색만으로 순위화하는 구조를 보였습니다. 지식 가이드 에이전틱 프레임워크(2608.19875)는 지식 그래프로 가설 공간 구성→누락 변수 식별→타겟 질문 생성이라는 전형적 에이전틱 루프를 의료 도메인에서 검증했습니다. MemGraphRAG(2606.00610, KDD 2026)나 MixRAGRec(2605.28175, KDD 2026) 등 선행 연구와 더불어, 그래프 구조를 '검색 증강'을 넘어 '에이전트 메모리·계획·추론' 기반으로 내재화하는 흐름이 주류화되고 있습니다.

**벡터 검색·임베딩 분야는 효율·비용 최적화에 집중**했습니다. The Embedder's Dilemma(2608.12875)는 LLM 임베딩이 추론 집약적 검색에서만 우위이며, 분류·클러스터링·STS에서는 경량 임베딩 모델이 1,000배 저렴하게 동급 성능 낸다는 비용-성능 Pareto 경계를 실측했습니다. Quantization Beyond Uniform Bit Allocation(2608.19388)은 MRL 임베딩의 기하 구조를 활용한 가변 비트 할당으로 저비트 영역에서 PQ 8%, SQ 18% 리콜 향상을 보였습니다. 두 논문 모두 '모델 크기·비용 대비 실제 태스크 이득'을 정량화해 실무 의사결정 근거를 제공한다는 점에서 의미가 큽니다.

**LLM 리랭커·심판 실용화와 에이전트 평가 다차원화**가 네 번째 트렌드입니다. Stopping and Routing LLM Judge Panels(2608.19802)는 심판 패널을 역할(복사/보완/전문가)별로 분류해 조건부 라우팅·조기 중단 정책을 학습, 평가 비용 대폭 절감하면서 품질 유지하는 운영 레시피를 제시했습니다.
