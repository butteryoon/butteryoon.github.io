## 이번 주 트렌드 요약 (2026-09-14 ~ 2026-09-20)

이번 주 RAG 연구는 **그래프 기반 접근의 'LLM-프리'화**가 뚜렷했습니다. G³RAG(2609.19622)는 엔티티 추출·토큰 생성 없이 문서 임베딩만으로 기하학적 이득 그래프를 구성해 멀티홉 증거 탐색에서 SOTA를 경신했으며, Algebraic Retrieval(2609.19482)은 에이전트가 쿼리 타임에 검색 연산을 대수적으로 조합하는 인터페이스를 제시해 '검색을 프로그래밍 가능하게' 만들었습니다. 두 논문 모두 LLM 호출 비용을 그래프 구성 단계에서 제거하거나 최소화하는 방향으로 RAG 아키텍처를 경량화했습니다.

**에이전트 하네스·런타임 계층의 '토큰 효율·회귀 테스트' 집중**이 두드러집니다. SoL-Pi(2609.20519)는 자동 연구 루프를 하네스 레벨에서 재귀 확장해 토큰 트래픽 ~45~49%, API 비용 ~1/3 절감을 달성했고, Chronicle(2609.20625)은 비결정적 경계를 불변 엔벨로프로 기록·컷-포인트 리플레이로 CI 회귀 테스트를 가능하게 했습니다. Harness 설계 실증 연구(2609.20804)는 계획 가이드와 검증기의 기여를 책임 수준별로 분해해 '단독 검증기가 전체 스택 거짓통과 방지 이득의 대부분을 흡수'함을 보였습니다. EvoSkill-GUI(2609.17653)는 GUI 에이전트 스킬을 배포 시점 무학습 진화 루프로 개선, 세 벤치마크에서 일관된 이득을 입증했습니다.

**벡터 임베딩·검색 분야는 '추론 품질 보존'과 '양자화 실측'으로 수렴**했습니다. CoFree(2609.20563)는 임베딩 학습 중 LLM 추론 능력이 붕괴되는 현상을 이중 보상 RL로 방지, 4B 모델이 22개 데이터셋 평균 +2.8 nDCG@10 향상시켰습니다. MERIT-Rank(2609.20131)는 다중 추론 궤적 통합으로 재랭킹 강건성 확보, 4B가 7B·32B 재랭커 상회. PTQ 실측 맵(2609.16391)은 4개 패밀리 24모델 전수 측정으로 INT4/INT8 배포 가이드라인을 제공했습니다.

**멀티-에이전트 평가·조정 이론이 '게임 이론·정보 이론' 기반으로 정교화**되었습니다. Bilevel Coordinated Reflection(2609.02750)은 오케스트레이터-워커를 바이레벨 게임으로 모델링해 반성의 수렴 조건·불가능성 정리·SRMA 알고리즘을 증명했고, AgentGrad(2609.08572)는 순차 개입·의미적 그래디언트 추상화로 프롬프트 최적화 2.5배 가속화. Claim-Safe 평가 프로토콜(2609.20538)은 재현성≠타당성 간극을 Refuse/Decompose/Refresh 3단계로 계약화했습니다. LLM 그룹이 인간 숙의 합의율을 과대추정함(2609.20543)을 스코어링 명시적 재현으로 입증했습니다.
