**조사 방법**: arXiv API 로 cs.IR / cs.CL / cs.MA / cs.AI / cs.LG 카테고리의 최신 등록분을 받아 날짜 창으로 거른 뒤, **실무 게이트**를 통과한 것만 남겼습니다. 통과 조건은 둘 중 하나입니다 — ① 받아서 돌려볼 수 있는 자원(코드·모델·데이터셋 링크)이 있다, ② 초록에 적용 판단의 근거가 되는 수치 비교가 있다. 둘 다 없는 논문은 읽는 사람이 자기 환경에서 할 게 없으므로 표에 올리지 않습니다. 선정분은 `arxiv.org/abs/...` 초록 페이지를 직접 열어 `citation_title` 메타와 대조했고, 등록일은 arXiv v1 "Submitted on" 기준입니다.
